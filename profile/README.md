### Overview

**Kanso-Project** develops clean, high-performance Kodi addons and utilities built around the principle of *Kanso* (簡素) — eliminating clutter and non-essential overhead.

### Active Projects

| Project | Category | Status | Description |
| :--- | :--- | :--- | :--- |
| **[Torii](https://github.com/Kanso-Project/torii)** | Core Sub-Project | Active | Gateway and routing module for Kanso-Project addons |
| **[repository.kanso](https://github.com/Kanso-Project/repository.kanso)** | Kodi Repository | Active | Official Kodi addon repository installer |

### Kodi File Manager Installation

1. Open **Kodi** and navigate to **Settings** (gear icon) → **File Manager**.
2. Select **Add source** and enter `https://kanso-project.github.io/` as the media location.
3. Name the source `kanso` and click **OK**.
4. Return to **Settings** → **Add-ons** → **Install from zip file** and select `kanso`.
